# Libro 3: ampliaciones y alternativas honestas

## Ampliación (upsell)
Cuando un cliente necesita algo adicional, ofrece un componente que resuelva un nuevo obstáculo y describe costo, alcance y posibilidad de rechazarlo. Una ampliación clásica añade servicio; una de menú ofrece opciones claras; una de referencia muestra diferencias reales; una de aplicación de crédito descuenta un pago previo bajo condiciones expresas. No cambies unilateralmente el plan ni sugieras que la compra original deja de funcionar.

## Alternativa menor (downsell)
Si el cliente rechaza la oferta, averigua por qué. Si la barrera es presupuesto, propone un plan de pago claro; si es alcance, una versión reducida con límites reales; si es incertidumbre, una prueba con obligaciones transparentes. “Trial with penalty” aparece como categoría en el libro, pero para esta comunidad se exige una explicación destacada de cargos y baja, y se debe descartar si provoca confusión.

## Regla comercial
Ofrece una alternativa solo si encaja con el problema. Mide aceptación, uso, reembolsos y satisfacción de cada opción; ingresos adicionales con quejas crecientes no son una mejora sostenible.
